# goal
Learn Neox by building a simple app — experience the full workflow from idea to installed app on your phone.

# feature
- [ ] Daily motivational quote on home screen
- [ ] Save favorite quotes
- [ ] Share a quote as text

# strategy
This is a guided tutorial. Neo walks you through each step. The app is intentionally simple so you can focus on learning the workflow, not the features.

# implementation phrases
- [ ] Step 1: Describe your app idea (done — this template pre-fills it)
- [ ] Step 2: Review the spec Neo writes
- [ ] Step 3: Say "go" to start the coding agent
- [ ] Step 4: Wait for build notifications
- [ ] Step 5: Try the app on your phone
- [ ] Step 6: Request one change to see the iteration cycle

# pre-coding review checklist
before calling `start_coding_task`, verify ALL items:
- [x] goal is specific and achievable in one coding session
- [x] each feature has clear acceptance criteria
- [x] screen flow documented (2 screens: quotes, favorites)
- [x] data model defined (quote text, saved boolean)
- [x] edge cases addressed (empty favorites, no network)
- [ ] user confirmed "go"

# references
- **docs/**: project docs, spec, screen flow
- **progress/**: build status, iteration log
