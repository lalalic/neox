# goal
Design and develop a game — from concept to playable prototype.

# feature
- [ ] Game concept and design document
- [ ] Core mechanics prototyping
- [ ] Art and asset management
- [ ] Level design
- [ ] Playtesting and iteration
- [ ] Build and distribution

# strategy
Design in docs/, prototype with make-app skill for mobile or web games, iterate based on playtesting feedback.

# implementation phrases
- [ ] Write game design document
- [ ] Prototype core mechanics
- [ ] Create art and assets
- [ ] Build playable demo
- [ ] Playtest and iterate

# onboarding
Ask the user:
1. What kind of game? (puzzle, platformer, RPG, casual)
2. Target platform? (iOS, web, both)
3. Any gameplay inspiration? (similar games)

# human-must
| When | What |
|------|------|
| Setup | Describe game concept |
| Before coding | Confirm game design doc |
| After build | Playtest on device, report bugs |
| Per iteration | Feedback on feel/balance |

# daily-assist
- Check coding agent progress on game feature
- "Build ready — time to playtest!"

# references
- **design/**: game design doc, mechanics, story
- **assets/**: sprites, sounds, music
- **builds/**: playable versions
- **docs/**: tech guides, platform requirements
- **progress/**: playtest feedback, milestones
