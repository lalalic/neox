# goal
Build and ship a mobile or web app — from idea to published product.

# feature
- [ ] App concept and requirements
- [ ] UI/UX design
- [ ] Development and coding
- [ ] Testing and QA
- [ ] App store submission
- [ ] User feedback and updates

# strategy
Use make-app skill to scaffold and build. Design in docs/, develop iteratively, test on device, submit to app store.

# implementation phrases
- [ ] Define requirements and design
- [ ] Scaffold project from template
- [ ] Develop core features
- [ ] Test and fix bugs
- [ ] Submit and launch

# onboarding
Ask the user:
1. What does the app do? (one sentence)
2. Who is it for? (target user)
3. Any special features? (camera, maps, payments, etc.)

# human-must
| When | What |
|------|------|
| Setup | Describe the app idea |
| Before coding | Confirm spec — say "go" |
| After build | Test on phone, report bugs |
| App Store | Apple ID login, review screenshots |

# daily-assist
- Check if coding agent has open PRs/issues
- Summarize build progress
- Ask "want to add a feature or fix something?"

# references
- **design/**: mockups, wireframes, user flows
- **docs/**: requirements, API docs, tech decisions
- **assets/**: icons, screenshots, marketing materials
- **progress/**: sprint plans, release notes
