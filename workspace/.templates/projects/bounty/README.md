# goal
Find and complete open-source bounties, bug bounties, and freelance coding tasks for revenue.

# feature
- [ ] Bounty source discovery (GitHub, Gitcoin, HackerOne, Bugcrowd)
- [ ] Opportunity evaluation and filtering
- [ ] Task tracking and submission management
- [ ] Earnings tracking
- [ ] Skill-based matching
- [ ] Portfolio of completed bounties

# strategy
Use web-search to discover bounties, evaluate effort/reward, track work in progress/, and build a portfolio of completed work.

# implementation phrases
- [ ] Set up bounty source feeds
- [ ] Evaluate and select first bounties
- [ ] Complete and submit work
- [ ] Track earnings and lessons learned
- [ ] Scale to higher-value bounties

# onboarding
Ask the user:
1. What skills do you have? (web, mobile, crypto, security)
2. Which platforms? (GitHub, HackerOne, Gitcoin)
3. How much time per week?

# human-must
| When | What |
|------|------|
| Setup | Skills, target platforms, time budget |
| Per bounty | Review finding before submission |
| Per bounty | Write the actual exploit/fix/PR |
| Per bounty | Submit on platform (may need auth) |
| Monthly | Review earnings and adjust strategy |

# daily-assist
- Search for new bounties matching skills
- "Found N new bounties. Top pick: $X for [description]"

# references
- **docs/**: bounty sources, evaluation criteria, submission guides
- **active/**: current bounty work in progress
- **completed/**: finished bounties and submissions
- **progress/**: earnings tracker, weekly reviews
