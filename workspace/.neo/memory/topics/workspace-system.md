# Workspace System

## Core Model
- `.github/` is the behavior layer.
- `.neo/` is the memory and report layer.
- The workspace should keep durable knowledge in files, not only in prompts or chat history.

## Recurring Themes
- Mobile-first, concise interaction
- Agent and skill orchestration
- Durable memory that survives across sessions
- Workspace refresh whenever the behavior surface changes
