# .neo

This is Neo's local memory home inside the workspace.

## Start Here
- Agent entrypoint: `agents/neo.agent.md`
- Mission: `mission.md`
- General memory index: `memory.md`

## Structure
- `agents/` - local Neo agent definitions
- `knowledge/` - stable reference material
- `memory/` - structured durable memory
- `reports/` - generated history and summaries

## Key Memory Files
- `memory/user-profile.md`
- `memory/projects/workspace.md`
- `memory/topics/workspace-system.md`
- `memory/topics/repo-directions.md`
- `knowledge/workspace-reference.md`

## Rule of Thumb
- Put durable facts in structured memory.
- Put reusable references in `knowledge/`.
- Keep generated summaries in `reports/`.
